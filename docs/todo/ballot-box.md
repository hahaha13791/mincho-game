# ballot-box (1번, 뱃속 패킹)

규칙: 6×4 격자에 표 뭉치 4종(2칸·3칸·ㄱ자·정사각형)을 드래그로 채움. 우클릭 회전, 칸 밖에 놓으면 버림.
발소리(12~24초 사이 랜덤) 2초 뒤 참관인 도착. 도착 전에 뚜껑을 닫아야 함.
목표 18칸 이상 + 도착 1초 이상 전 = 완전범죄, 18칸 이상 + 1초 미만 = 미션성공, 그 외 = 적발. 수치는 `ballot_box.gd`의 `@export`.

- [~] 격자 로직과 등급 판정 (`packing_grid.gd`, `ballot_box_rules.gd`)
  - 테스트(자동): `-s res://minigames/ballot_box/test_rules.gd` → TEST OK (통과)
- [~] 플레이 씬 (`ballot_box.tscn`/`.gd`): 드래그, 회전, 발소리, 뚜껑, 튜토리얼·결과 오버레이
  - 테스트(자동): 씬 로드·구동 시뮬레이션에서 에러 없음, 득표 반영 확인 (통과)
  - 테스트(수동): 마우스로 드래그·우클릭 회전이 자연스러운지, 발소리 예고가 보이는지, 18칸이 너무 쉽거나 어려운지 확인
- [ ] 수동 플레이 테스트 후 수치 조정 (목표 칸, 경고 시점, 안전 여유)
  - 테스트(수동): 3개 등급이 모두 나올 수 있는지 확인

임시 처리: 결과 버튼은 허브가 없어서 `GameState.reset()` 후 재시작. hub 단계에서 `Flow.go_hub`로 교체.
