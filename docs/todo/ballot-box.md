# ballot-box (1번, 임신한 투표함)

규칙: 중력 있는 투표함(폭 6, 높이 4)에 접힌 모양이 제각각인 표(직사각형 조각 조합 4종)를 마우스로 끌어다 떨어뜨려 쌓음. 합쳐지지 않고 계속 쌓임.
발소리(12~24초 사이 랜덤) 2초 뒤 참관인 도착. 도착 전에 뚜껑을 닫아야 함.
목표 6장 이상 + 도착 1초 이상 전 = 완전범죄, 6장 이상 + 1초 미만 = 미션성공. 표가 선을 넘어 뚜껑이 안 닫히거나 장수 미달이거나 참관인에게 들키면 적발. 수치는 `ballot_box.gd`의 `@export`.

- [~] 표 물리와 등급 판정 (`ballot_paper.gd`, `ballot_box_rules.gd`)
  - 테스트(자동): `-s res://minigames/ballot_box/test_rules.gd` → TEST OK (통과)
- [~] 플레이 씬 (`ballot_box.tscn`/`.gd`): 드래그앤드롭, 선 넘김 판정, 발소리, 뚜껑, 튜토리얼·결과 오버레이
  - 테스트(자동): 표 6장을 집어 떨어뜨리고 뚜껑을 닫는 시뮬레이션에서 에러 없음, 득표 반영 확인 (통과). 선 넘김 실패 경로는 아직 시뮬레이션하지 않음
  - 테스트(수동): 드래그가 자연스러운지(집은 표는 속도로 마우스를 따라오며 쌓인 표를 통과하지 않음), 표 모양 4종이 6장 쌓기에 너무 쉽거나 어려운지 확인
  - 테스트(실제 창): 전체화면에서 실제 마우스로 집어 끌면 표가 따라오는 것 확인 (통과)
  - 테스트(수동): 새 표가 생길 때 집은 표가 밀리지 않는지 (대기 표는 충돌을 꺼 둠. 시뮬레이션만 통과, 실제 창 미확인)
  - 참고: 얼린(`freeze`) RigidBody3D의 `position` 직접 대입은 물리 엔진이 덮어써서 안 먹힘. 얼려도 충돌은 남아 있어서 대기 표는 `set_waiting()`으로 충돌도 끔
- [ ] 수동 플레이 테스트 후 수치 조정 (목표 장수, 경고 시점, 안전 여유, 표 모양)
  - 테스트(수동): 3개 등급이 모두 나올 수 있는지 확인

임시 처리: 결과 버튼은 허브가 없어서 `GameState.reset()` 후 재시작. hub 단계에서 `Flow.go_hub`로 교체.

## 아이디어 (구현 안 함, 기록만)

표를 접는 과정을 게임에 넣기: 플레이어가 투표용지에 도장을 찍고, 마우스를 누른 채 움직여 그은 선을 기준으로 종이를 접음. 접혀서 나온 모양을 쌓는 표로 씀. 지금은 미리 정해 둔 모양 4종을 쓰고 있음.
