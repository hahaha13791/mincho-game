# todo 인덱스

작업 중인 파일만 연다. 상태: `[ ]` 미착수 / `[~]` 코드 작성됨, 미검증 / `[x]` 테스트 완료.
`[x]`는 각 작업의 `테스트:`(자동 = Claude가 실행, 수동 = 사용자 플레이 확인)를 통과해야 쓴다.

| 파일 | 내용 | 진행 |
|---|---|---|
| foundation.md | 해상도, 팔레트, Theme, 스타일 규칙 | 0/4 |
| common.md | Flow, MinigameBase, 튜토리얼, 결과 화면 | 0/4 |
| hub.md | 메뉴형 허브, 미니게임 목록 | 0/3 |

## 순서
1. foundation → common → hub → 1번 미니게임
2. **스타일 확정**: 1번 미니게임 완성 직후 조명·그림자·재질·UI 기준을 확정하고 1번에 반영 (2번부터는 그 기준대로)
3. 나머지 미니게임을 하나씩. 규칙 미정 항목은 만들기 전에 정한다
4. 타이틀, 최종 개표, 3D 전략실, 밸런싱, 이름 확정
