# hub (공통 흐름: 결과 화면, 화면 전환, 임시 선택 화면)

- [~] `Flow` 오토로드(`common/flow.gd`): `go_hub()`, `start(entry)`
- [~] 공통 결과 화면 (`common/result_screen.gd`): 등급, 메시지, 득표 변화, "작전본부실로" 버튼. 미니게임은 `GameState.submit_result()` 후 `ResultScreen.open()`만 호출
- [~] 미니게임 목록 (`main/minigame_list.tres`): id, 표시 이름, 씬 경로. 씬이 비어 있으면 "준비 중"
- [~] 임시 선택 화면 (`main/hub.tscn`/`.gd`): 완료한 미니게임은 등급을 표시하고 비활성화
  - 테스트(자동): 허브 실행 시 에러 없음, 결과 화면 생성 후 버튼으로 허브 복귀 시 에러 없음 (통과)
  - 테스트(수동): 1번 플레이 → 결과 → 허브에서 완료 표시와 득표 확인
  - 확인 필요: 1번 외 id(`piano_ballot` 등)는 임시로 지은 영문 id. 미니게임을 만들 때 폴더명과 함께 확정
- [ ] 미니게임을 만들 때마다 `minigame_list.tres`의 `scene`만 채우면 허브에서 열림
- [~] 선택 화면 3×3 격자: 가운데 = 개표 당일(7개를 다 끝내면 "준비 중"으로 바뀜, 누를 수 없음), 둘레 8칸 = 미니게임 7개 + 빈 칸 1개("준비 중"). 8번째 칸은 미니게임이 정해지면 `minigame_list.tres`에 항목만 추가
  - 테스트(자동): 허브 실행 시 에러 없음, 9칸 구성 확인 (통과)
  - 테스트(수동): 실제 화면에서 격자 크기와 글자 배치
- [~] 최종 개표 (`main/final_count.tscn`/`.gd`, 판정은 `common/final_rules.gd`): 가운데 칸을 7개 완료 후 누르면 득표 막대 개표 연출 → 승패 → 칭호 → 종합점수 → 미니게임별 등급, 전부 완전범죄면 추가 이벤트 문구, "처음부터" 버튼(`GameState.reset()`)
  - 칭호(위에서부터): 전부 완전범죄 "그림자 민초단장" / 전부 적발 "민초의 수치, 즉시 제명" / 이기고 적발 2회 이상 "운 좋은 행동대장"(7개 중 적발 3회로는 득표상 이길 수 없어 2회로 함) / 이기고 적발 0·완전범죄 4회 이상 "소리 없는 민초 참모" / 이김 "동네 민초 대장" / 짐+적발 1회 이하 "한 끗 모자란 민초단원" / 그 외 "열세 민초단 평단원"
  - 득표 변화 수치를 `[+7, +3.5, -3]`으로 올림 (전부 미션성공이면 54.5%로 승리, 6개 미션성공+1개 적발이면 48%로 패배). 승리 기준은 50% 초과(동률은 패배). 플레이 테스트로 재조정
  - 테스트(자동): `-s res://common/test_final_rules.gd` → TEST OK (통과). 7개 완전범죄로 채운 뒤 허브 → 개표 시뮬레이션에서 에러 없음, 막대 79% 확인 (통과)
  - 테스트(수동): 실제 화면에서 개표 연출 속도와 배치, 칭호 문구
- [~] 리더보드 (`common/leaderboard.gd`, 화면 `main/leaderboard.tscn`/`.gd`): 개표 화면의 "리더보드에 등록"으로 `user://leaderboard.json`에 저장하고 득표·등급을 초기화한 뒤 리더보드 화면으로 이동. 허브의 "리더보드" 버튼으로도 볼 수 있음
  - 순위: 종합점수 > 최종 득표 > 먼저 등록한 순. 이름은 입력이 마우스뿐이라 자동으로 "민초단원 N호". 상위 10명 표시, 방금 등록한 항목은 ★와 색으로 강조(10위 밖이면 아래에 따로). 줄마다 칭호와 미니게임별 등급 약자(완/미/적, 플레이한 순서)
  - 깨진 파일은 `.bak`으로 보존하고 새로 시작
  - 테스트(자동): `-s res://common/test_leaderboard.gd` → TEST OK (통과). 등록 → 초기화 → 화면 표시 시뮬레이션에서 에러 없음, 10위 밖 항목이 ★와 함께 아래에 나오는 것 확인 (통과)
  - 테스트(수동): 실제 화면에서 줄 배치, 등록 후 화면 전환
  - 확인 필요: 전시장 PC 하나에 저장되는 로컬 파일이라 기기를 바꾸면 기록이 없음. 이름 입력(마우스로 글자 고르기 등)과 기록 초기화 방법(전시 시작 전 파일 삭제)은 미정
- [~] 타이틀 (`main/title.tscn`/`.gd`, 시작 씬): 제목, 입단 문구, 현재 득표 막대(30:70), "입단하기"(허브로)와 "리더보드" 버튼. 타이틀에 들어올 때 `GameState.reset()`. 개표의 "등록하지 않고 처음부터"와 등록 직후 리더보드의 "돌아가기"는 타이틀로 감(허브에서 리더보드를 연 경우는 허브로)
  - 테스트(자동): 타이틀 실행 시 에러 없음, 입단 버튼으로 허브 이동 확인
  - 테스트(수동): 실제 화면에서 막대와 글자 배치
  - 확인 필요: 전시 중 방문자가 도중에 떠났을 때 다음 사람을 위한 초기화 방법(허브에 "타이틀로" 버튼을 둘지, 일정 시간 입력이 없으면 자동 복귀할지)
- [ ] 허브 연출(작전본부실)

임시 처리: 허브 아래의 테스트용 버튼 둘 — "처음부터"(`GameState.reset()`), "7개 모두 완료"(프리셋: 전부 완전범죄/전부 미션성공/미션성공 6+적발 1/완전범죄 5+적발 2/전부 적발/무작위). 개표 화면을 빨리 보려는 용도. 최종 개표/타이틀이 생기면 제거.
