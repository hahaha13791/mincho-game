# 게임 안 텍스트 목록

플레이어가 보는 문구를 전부 모은 것(2026-11-26 기준). 코드에 반영함(2026-11-26). 문구를 바꿀 때는 이 파일과 `위치`의 파일·줄을 같이 바꾼다. 줄 번호는 반영 전 기준이라 조금 어긋날 수 있다.
- `%d`, `%s`, `%.1f%%` 같은 자리 표시는 숫자·글자가 들어갈 자리라 지우면 안 된다(순서도 그대로). `\n`은 줄바꿈
- **고친 점** 칸: 원래 문구에서 무엇을 왜 바꿨는지. 비어 있으면 그대로 둔 것
- 뺀 것: 규칙 테스트(`test_*.gd`) 메시지, 오류 기록(`리더보드 파일이 깨져…`, `리더보드를 저장하지 못했다`), 개발용 검사 문구(`piano_ballot.gd:61`), 전시 전에 없앨 테스트 버튼(`hub.gd` 13~18·243·253줄)

## 고치는 원칙 (투표함 먹이주기 수정에서 정리)

1. **이름은 실제 선거 부정 은어를 쓰지 않고, 이름만 보고 할 일을 알게** (피아노표·올빼미표 → 몰래 찍어라!·암흑 침투)
2. **튜토리얼은 시스템 설명이 아니라 플레이어가 할 일.** 규칙 나열을 줄이고 목표·보상으로 말한다. 등급 이름(미션성공·완전범죄)과 맞춘다
3. **결과 문구는 비유보다 화면에 보이는 것, 그리고 그 등급이 나온 원인.** 잘했을 때는 주어를 플레이어로
