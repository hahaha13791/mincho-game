# 게임 피드백
## 각 미니게임 별
### 1. 임신한 투표함
 - 성공 조건: 12개 대성공 / 10개 성공
 - 지금 종이 모양이 너무 테트리스 모양. 나중에 디자인에서 바꾸면 문제 없나? 모델 바꿨을때 난이도 재조정 필요
 - 투표함에 투표함이라는 단어가 박스 외곽에 적혀져있으면 좋겠다.
 - 쿵쿵쿵과 실제 감시자 도착사이에 텀이 짧음.
 - 쿵쿵쿵도 쿵과 쿵 사이의 간격이 조금만 여유로웠으면 좋겠음. 쿵이 하나씩 등장하게끔

### 2. 피아노표
  - 표는 하얀색으로 통일. 단 찍혀져있는 도장을 민트색으로 변경. 기존 갈색 종이
  | 기존 | 변경 |
  |---|---|
  | 갈색 종이 | 공백의 흰 종이 |
  | 민트 종이 | 민트색 도장이 찍힌 흰 종이 |
  
  - 멀리에 반대로 흘러가는 레일 추가 -> 몇 초뒤에 본 레일에 그대로 나옴. 즉, 박자 미리보기(레퍼런스: 비츠앤밥스의 HammerTime)
  - 엇박이나 1/16 박 등, 다양한 박자 추가(레퍼런스: 비츠앤밥스의 HammerTime)

### 3. 샌드위치표
  - 지금은 박스모양이라서 종이 느낌이 안남. 나중에 서류가 쌓인 느낌으로 고칠 것

### 4. 올빼미표
  - 감시자가 불이 켜져있을때도 움직이게해서 사용자가 경로를 예상할 수 잇게 할 것.
  - 2*1, 1*1 혹은 ㄱ자 모양 등 다양한 엄폐물을 만들고, 나중에 투표소에 있을만한 물품으로 디자인 대체할 것
  - 좀 더 넓은 맵 만들기

### 5. 사라지는 잉크
  - 다리미가 위에서 아래로 내려오도록 변경
  - 종이 별 잉크가 지워지는 시간을 더 다양하게 해야됨
    - 각 종이별 정해진 시간에 따라 외곽 색변화 속도 차이 두기
  - 종이가 바로 나타나는 게 아니라 왼쪽에서 오른쪽으로. 처리가 끝난 종이도 마찬가지로 오른쪽으로 사라지게 만들기

### 6. 미친 쥐
  - 저수지를 '민트초코아이스크림가게'로 변경
  - 중앙에 표지판 생성. 왼쪽버튼을 누르면 왼쪽을 가리키게 회전. 오른쪽버튼을 누르면 오른쪽을 가리키게 회전
  - 버튼을 누르지 않아도, 현재 표지판에 따라 이동시킬 것
  - 유권자가 속도 템포 증가.
