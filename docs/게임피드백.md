# 게임 피드백
## 각 미니게임 별
### 1. 임신한 투표함
 - 성공 조건: 12개 대성공 / 10개 성공
 - 지금 종이 모양이 너무 테트리스 모양. 나중에 디자인에서 바꾸면 문제 없나? 모델 바꿨을때 난이도 재조정 필요
 - 투표함에 투표함이라는 단어가 박스 외곽에 적혀져있으면 좋겠다.
 - 쿵쿵쿵과 실제 감시자 도착사이에 텀이 짧음.
 - 쿵쿵쿵도 쿵과 쿵 사이의 간격이 조금만 여유로웠으면 좋겠음. 쿵이 하나씩 등장하게끔

### 2. 피아노표
  - 표는 하얀색으로 통일. 단 찍혀져있는 도장을 민트색으로 변경. 기존 갈색 종이
  | 기존 | 변경 |
  |---|---|
  | 갈색 종이 | 공백의 흰 종이 |
  | 민트 종이 | 민트색 도장이 찍힌 흰 종이 |
  
  - 멀리에 반대로 흘러가는 레일 추가 -> 몇 초뒤에 본 레일에 그대로 나옴. 즉, 박자 미리보기(레퍼런스: 비츠앤밥스의 HammerTime)
  - 엇박이나 1/16 박 등, 다양한 박자 추가(레퍼런스: 비츠앤밥스의 HammerTime)
