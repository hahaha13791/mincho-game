# 민초의, 민초를 위한, 민초에 의한 — 기획서

Nov 10, 2026 · @blacksheep

## 개요

소수파 민초단이 되어 옛 아날로그 부정선거 수법을 미니게임으로 해보는, 전시용 싱글플레이 미니게임 모음이다.

- **프로젝트명**: 민초의, 민초를 위한, 민초에 의한
- **형식**: 싱글플레이 미니게임 모음, 전시장 체험용 (미니게임 6개 전부, 순서는 자유)
- **개발**: 1인, Godot 4, PC+마우스

**작품설명 (전시 제출용)**

'민트초코 대 반민트초코'라는 결과가 아무 의미 없는 투표를 무대로, 소수파인 민초단이 되어 역사 속 아날로그 부정선거 수법을 직접 체험하는 미니게임 모음입니다. 플레이어는 투표함 미리 채우기, 개표 중 상대 표 무효로 만들기, 정전 틈 바꿔치기 등 실제로 있었던 수법을 각각의 미니게임으로 해보며, 결과에 따라 등급과 최종 개표 결과를 받습니다. 사람의 손을 거치는 기존 종이 투표 방식의 구조적 한계를 게임으로 풀어내어, 블록체인 기반 전자투표가 왜 필요한지 생각해볼 계기를 제공합니다.

## 세계관과 톤

결과가 아무 의미 없는 선호 싸움을 주제로 삼아, 웃음을 살리고 실제 정치와의 연결을 끊는다.

- **투표 주제**: 민초 vs 반민초 (두 편 색이 초록 대 갈색으로 선명해 표가 섞이거나 바뀌는 게 한눈에 보임)
- **플레이어**: 소수파인 민초단. 시작은 열세(예: 민초 30% 대 반민초 70%)
- **무대**: 가상의 마을. 마을회관, 개표대, 갈림길 같은 작은 공간
- **톤**: "고작 이걸로 이렇게까지?"의 웃음. 실패 장면도 웃기게 연출
- **참고작**: Untitled Goose Game(마을 사람들 몰래 장난치기), WarioWare·리듬 천국(짧은 미니게임 모음), 쿠우키요미(유머 중심)

**정치색 배제 원칙**

- 실제 정당·인물·선거를 연상시키는 이름, 색, 상징을 쓰지 않는다.
- 수법은 '옛날 종이 투표에서 있었던 것'으로만 다루고, 현재 선거에 대한 주장으로 읽히지 않게 한다.
- 최근 사례(다른 나라의 현재 의혹 등)는 소재로 쓰지 않는다.

## 게임 구조

미니게임은 조작과 등급을 각자 따로 갖고, 관람객이 골라서 하나씩 한다. 공통 조작 규칙으로 일관성을 맞추지 않고, 수법마다 가장 어울리는 조작을 쓴다.

1. 타이틀: 민초단 입단, 현재 득표(민초 열세) 표시
2. 미니게임 선택 화면: 수법 카드 목록에서 고름
3. 튜토리얼(마리오 파티식 짧은 규칙 설명) → 미니게임 플레이 (하나당 30초\~1분)
4. 미니게임 결과: 등급 + 득표 변화 표시 → 선택 화면으로 복귀
5. 최종 개표: 6개를 모두 마치면 종합 결과와 칭호

**설계 원칙**

- 6개를 모두 하되 순서는 자유롭게 고른다. 미니게임이 독립적이라 마감 직전에 덜 된 미니게임을 빼도 전체가 무너지지 않는다.
- 미니게임마다 시작 전 짧은 튜토리얼을 둔다(마리오 파티식). 튜토리얼은 몇 초 안에 끝나야 한다.
- 미니게임끼리 묶는 것은 세계관, 화풍, 같은 형식의 결과 화면이다.

## 미니게임 목록

후보는 6개(1, 2, 4, 5, 6, 9)다. 이름은 구상용 수법 이름이다. 게임 안 이름은 실제 부정선거 은어를 피해 따로 정했다: 임신한 투표함 → 투표함 먹이주기, 피아노표 → 몰래 찍어라!, 샌드위치표 → 택갈이 대작전, 올빼미표 → 암흑 침투, 사라지는 잉크 → 열과 함께 사라지다, 미친 쥐 → 표지판 사보타주(`main/minigame_list.tres`). 모두 선거를 관리하는 쪽이 유권자 몰래 표를 망가뜨리는 수법이며, 입력은 PC+마우스다.

## 등급과 종합 결과

미니게임마다 등급을 주고, 점수가 아니라 등급을 득표 변화로 바꿔 최종 개표 결과를 만든다. 난이도가 다른 미니게임끼리도 공정해진다.

| 등급 | 조건 (예시) | 득표 변화 (예시) |
| --- | --- | --- |
| 완전범죄 | 한 번도 안 들키고 목표 달성 | 민초 +5%p |
| 미션성공 | 목표 달성, 들킬 뻔한 적 있음 | 민초 +2%p |
| 적발 | 들킴 | 민초 -3%p |

- **최종 개표**: 민초 30% 대 반민초 70%에서 시작해 등급만큼 움직인다. 모든 미니게임에서 미션성공 이상이면 역전하도록 숫자를 맞추고, 전부 완전범죄면 추가 이벤트가 나온다. "하나만 더 하면 이길 수 있었는데"가 다시 하게 만드는 동기다.
- **칭호**: 등급 조합에 따라 웃긴 칭호를 준다. 예: 전부 완전범죄 "그림자 민초단장", 전부 적발 "민초의 수치, 즉시 제명", 들킨 횟수가 많은데 이김 "운 좋은 행동대장". 칭호 카드는 사진으로 남기기 좋게 디자인한다.
- **리더보드**: 종합점수로 순위를 매기고, 옆에 미니게임별 등급을 세부 점수로 함께 보여준다. 칭호도 이 자리에 표시한다. 종합점수는 원점수가 아니라 등급 점수의 합이라 난이도 차이의 영향이 작다. 동시 대전 없이도 같이 온 관람객끼리 번갈아 경쟁할 수 있다.

등급 조건과 득표 변화 수치는 플레이 테스트로 조정한다.

## 전자투표와의 연결

게임은 종이 투표의 한계까지만 다루고, 블록체인 전자투표는 관람객이 생각해볼 거리로 남긴다. 게임 안에서 전자투표를 시연하지 않는다.

- 고른 수법은 모두 "유권자는 자기 표가 어떻게 됐는지 모른다"는 점을 파고든다. 블록체인 투표의 장점(내 표가 기록·집계됐는지 내가 확인)과 직접 맞물린다.
- "공정한 선거를 지키기" 같은 가치 판단 문구는 쓰지 않는다.

## 기술 스택과 작업 방식

Godot 4 일반(Standard) 버전과 GDScript로 만들고, 코딩은 로컬 프로젝트 폴더에서 Claude Code와 함께 한다.

| 항목 | 결정 | 이유 |
| --- | --- | --- |
| 엔진 | Godot 4 일반 버전 | C#이 필요 없고, .NET 버전과 달리 웹 내보내기도 남겨둠 |
| 언어 | GDScript (Godot 4 문법) | 미니게임 규모에 충분하고 예제가 많음 (2D·3D 모두 가능) |
| 시점 | 실시간 3D + 고정 카메라 (3D 모델을 2D 평면에 배치) | 조명·그림자·깜빡임 효과를 넣기 쉽고, 미리 렌더링한 이미지보다 수정이 간편함 |
| 화풍 | 단색 로우폴리, 텍스처 없음, 옛은 그림자 (레퍼런스: Untitled Goose Game) | 민초·반민초 색 대비가 잘 살고, 텍스처를 안 그려도 돼 혼자 만들기 좋음 |
| 에셋 | Kenney(소품), Quaternius·KayKit(캐릭터), 모두 CC0 | 출처 표기 없이 쓸 수 있고 모델링 부담을 줄임. 단색으로 재질만 바꿔 화풍을 맞춤 |
| 버전 관리 | git | Claude가 잘못 고쳐도 되돌릴 수 있음 |
